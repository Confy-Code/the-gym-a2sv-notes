## EXERCISES FOR JAVASCRIPT'S EVENT LOOP

### Guidelines and Instructions 
---

1. Try predicting the output manually, using a pen and a paper
2. Sketch the Callstack, Task and Microtask queues and Web APIs to better visualize the functionality of event loop
3. Use your preferred IDE to compare you answers with the actual logs.
4. If you want to visualize how the IDE conceptually got the answers, I recommend using [this online tool](https://event-loop-visualiser.ishanbagchi.com/).


          HAPPY CODING :)
